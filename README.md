# sparking-build-ci

Repo público SOLO de compilación para la build privada de Dragon Ball Sparking! Zero.

Contiene únicamente el workflow de GitHub Actions y el parche del lanzador
(traducción al español + ajustes de rendimiento). NO contiene archivos del
juego, claves ni la .ipa resultante: todo eso vive en el repo privado
ShebasK0908/sparking-build, al que el workflow accede con un token guardado
como secreto de este repo.
